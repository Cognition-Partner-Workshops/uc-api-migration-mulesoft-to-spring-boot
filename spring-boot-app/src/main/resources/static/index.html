Employee Service

Spring Boot migration target for the MuleSoft Employee Services API

MuleSoft → Spring Boot Migration

About this service

This service is the Spring Boot 3.x target of the MuleSoft → Spring Boot migration. It reimplements the Employee Services API — goals, learning status, payroll dates, and PTO — against the OpenAPI contract in contracts/openapi.yaml.

System

  • GET /health Health check — database connectivity status

API endpoints

  • GET /api/employee/{employeeId}/goals Retrieve goals for an employee
  • GET /api/employee/{employeeId}/learning-status Retrieve learning status for an employee
  • GET /api/employee/{employeeId}/next-pay-date Retrieve the next pay date for an employee
  • GET /api/employee/{employeeId}/pto/balance Retrieve PTO balance for an employee
  • GET /api/employee/{employeeId}/pto/schedule Retrieve PTO schedule for an employee
Employee Service — contract source of truth: contracts/openapi.yaml
